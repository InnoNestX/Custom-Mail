# Custom Mail docs site

VitePress documentation for [Custom Mail](https://github.com/InnoNestX/Custom-Mail).

## Local

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
```

Output: `_site/` (deployed by GitHub Actions to Pages).

Published at: https://innonestx.github.io/Custom-Mail/
